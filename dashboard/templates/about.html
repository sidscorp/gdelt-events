About GDELT Monitor

A real-time global news intelligence system

What it does

Every 15 minutes, the pipeline downloads the latest articles from GDELT's Global Article List and Global Knowledge Graph. Articles are loaded into a DuckDB analytical database and scanned against multiple classification systems — keyword pattern matching, entity recognition, and semantic embeddings.

The system ships with a few built-in monitoring views as examples of what's possible:

  • Medical Device Companies — matches articles mentioning any of ~4,000 FDA-registered manufacturers by name
  • Supply Chain Alerts — tracks geopolitical shocks, trade disruptions, natural disasters, and logistics signals
  • Semiconductor & Chip Geopolitics — monitors US-China trade restrictions, fab capacity, and chipmaker activity

Because a major story gets reported by hundreds of outlets at once, near-duplicate articles about the same event are rolled up into a single event card — each with a shareable permalink — so the feed shows distinct stories rather than the same headline forty times. And for any topic or time window, an on-demand AI briefing summarizes what's actually happening across the matched coverage, with citations back to the source articles.

How it works

Articles are scanned using Aho-Corasick automata — a trie-based algorithm that finds all occurrences of thousands of patterns in a single linear pass. Matches are materialized into indexed cache tables so the dashboard can serve results in under a second. The system maintains a rolling 60-day window and prunes older data to keep storage bounded. New articles are classified every 15 minutes.

Alongside keyword matching, each English article is embedded with a local neural model (nomic-embed-text via Ollama) and indexed in a FAISS vector store. A leader-clustering pass groups articles whose embeddings are near-duplicates into persistent event clusters — this is what powers the rolled-up event cards and their permalinks. The AI briefings are generated on demand from the top events in a view by gpt-oss-120b (an open-weights model, via a self-hosted LLM gateway), streamed token-by-token and cached so repeat views load instantly. Topic pills are precision-gated by an LLM judge — see the methodology page for the full logic behind everything displayed.

The tech stack

  • Data source GDELT Project v2 (GKG) + v3 (GAL)
  • Database DuckDB 1.5.1 (analytical) + SQLite (user data)
  • Pattern matching Aho-Corasick via pyahocorasick
  • Embeddings nomic-embed-text v1.5 via Ollama
  • Event clustering FAISS IVF-PQ + exact-cosine re-rank
  • AI briefings gpt-oss-120b via self-hosted LiteLLM gateway
  • Web framework Flask + Waitress
  • App Installable PWA (service worker)
  • Infrastructure Cloudflare Tunnel (zero-trust)
  • Language Python 3.13
  • Hosting Self-hosted, NVIDIA RTX 4060
