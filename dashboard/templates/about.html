About GDELT Monitor

Real-time global news intelligence for supply chain awareness

Why this exists

Medical device supply chains are global, complex, and fragile. A factory fire in one country, a tariff announcement in another, or a natural disaster near a key manufacturing hub can cascade into shortages and delays that affect patient care. Yet most supply chain monitoring is reactive — you learn about a disruption after it's already impacting you.

GDELT Monitor was built to close that gap. It continuously ingests the GDELT Project's global news feed — over 25 million articles from tens of thousands of sources worldwide — and surfaces signals that matter: FDA-registered company mentions, supply chain disruption keywords, geopolitical shocks, trade policy changes, and natural disasters at manufacturing hubs.

How it works

Every 15 minutes, the pipeline downloads the latest articles from GDELT's Global Article List (GAL v3) and Global Knowledge Graph (GKG v2). Articles are loaded into a DuckDB analytical database and scanned using Aho-Corasick multi-pattern string matching — a trie-based algorithm that finds all occurrences of thousands of company names and keywords in a single linear pass over the text.

Matches are materialized into indexed cache tables so the dashboard can serve results in under a second for any time window. The system maintains a rolling 60-day window of data, pruning older articles to keep storage bounded.

Custom monitoring pills let registered users define their own keyword sets — the system builds a combined pattern automaton and scans the full article corpus, with new articles tagged incrementally on each 15-minute cycle.

The tech stack

  • Data source GDELT Project v2 (GKG) + v3 (GAL)
  • Database DuckDB 1.5.1 (analytical queries) + SQLite (user data)
  • Pattern matching Aho-Corasick via pyahocorasick
  • Web framework Flask + Waitress (Windows WSGI)
  • Infrastructure Cloudflare Tunnel (zero-trust, no exposed ports)
  • Language Python 3.13
  • Hosting Self-hosted on a home server with an NVIDIA RTX 4060
